积分说明

本页整理当前应用的积分结算规则（算法版本 v2.3）：中八三种模式的胜负结算、九球追分的净胜分折算与球数难度系数，以及排名统计口径。所有规则由积分引擎统一执行，保证全员口径一致。

总则

积分总则

积分引擎 v2.3 的设计原则：参与即得分、胜率导向、全程可追溯。以下规则适用于协会内全部中八与九球追分对局。

1参与即得分

  • 任何一场完赛，双方/各方都获得正积分，不存在负分结算
  • 每打一局，每位选手额外获得 +0.1 局参与分（中八/九球通用，鼓励多打多赛）

2胜率导向

  • 胜者收益显著高于负者，胜率越高积分增长越快
  • 中八模式二与九球追分还会按净胜幅度放大胜者收益

3可追溯

  • 每场对战结束后由积分引擎统一结算，变动写入积分流水（points_logs）
  • 每条流水标注算法版本号（当前 v2.3），历史结算可按原版本追溯

4排名口径

  • 积分榜按总积分降序排列，赛季口径为每年 9 月至次年 8 月
  • 胜率 = 胜场 ÷ 总场次；九球追分按净胜分判胜/平/负计入战绩
中八

中八积分规则

中八按对战模式分别结算，胜者基础分 +3、负者参与分 +1，再叠加清台奖励与局参与分。

1模式一 / 模式三（定点击球 / 逐杆记录）

  • 胜者基础分 +3，负者参与分 +1
  • 叠加：一杆清台每局 +1（胜负双方均计）＋ 局参与分（总局数 × 0.1，双方均计）
示例：模式一战满 5 局，胜者清台 1 局 → 胜者 3 + 1×1 + 5×0.1 = 4.5 分，负者 1 + 5×0.1 = 1.5 分

2模式二（记分制）

  • 单局净胜球 = 1 + 对方剩余球数；全场净胜球为各局之和
  • 胜者得分 = max(3, 3 + 净胜球 × 0.5)：净胜球只放大胜者收益，净胜为负时保底 +3
  • 负者固定参与分 +1；清台奖励与局参与分与模式一相同
示例：净胜球 +5、清台 1 局、共 4 局 → 胜者 3 + 5×0.5 + 1 + 4×0.1 = 6.9 分，负者 1 + 4×0.1 = 1.4 分
九球追分

九球追分积分规则

九球追分按净胜分折算积分，并按使用球数乘难度系数；追分场内的犯规罚分、大小金奖励先计入场内分，完赛后再统一换算。

1计算公式

  • 净胜分 = 终场分 − 初始分（默认初始分 100）
  • 净胜分 > 0 记胜、= 0 记平、< 0 记负，按净胜幅度线性折算积分
  • 球数越多难度越大，难度系数越高（见下表）；未记录球数时按 4 球系数 1.0 结算
  • 单场结算保底 0.5 分，保证参与即有收获
积分 = ( 参与基础分 1 + 净胜分 × 0.1 ) × 球数难度系数 + 局数 × 0.1，单场保底 0.5 分
示例：9 球制（系数 ×1.5），终场 130 分（净胜 +30），共 20 局 → (1 + 30×0.1) × 1.5 + 20×0.1 = 8.0 分
